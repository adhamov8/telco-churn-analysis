# Telco Customer Churn Analysis

Учебный проект по анализу оттока клиентов телеком-компании на основе датасета Telco Customer Churn.

## Задачи

В рамках анализа исследованы:

- связь между возрастной категорией клиента и оттоком;
- зависимость оттока от количества подключённых дополнительных услуг;
- различия в оттоке между пользователями DSL и Fiber optic.

## Используемые инструменты

- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Основные выводы

- Клиенты старшей возрастной категории имеют более высокий уровень оттока.
- С увеличением количества подключённых дополнительных услуг доля оттока снижается.
- При одинаковом количестве дополнительных услуг отток среди пользователей Fiber optic выше, чем среди пользователей DSL.
